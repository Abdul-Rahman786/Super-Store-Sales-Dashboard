# Super-Store-Sales-Dashboard
The Super Store Sales Dashboard is a Power BI project designed to visualize and analyze sales data for a fictional super store. This dashboard provides key insights into sales performance, including total sales, quantity sold, profit, and average delivery time across different segments, categories, payment modes, and shipping methods.Key features include:
Interactive charts and graphs for monthly sales and profit trends (2019-2020).
Breakdown of sales by segment (Home Office, Consumer, Corporate), category (Office Supplies, Technology, Furniture), sub-category, and payment mode (Online, COD).
Visual representation of sales by shipping mode and order date trends.
User-friendly interface with filters for regional data (Central, East, South, West).
This project showcases data visualization skills, Power BI proficiency, and the ability to derive actionable business insights from complex datasets.
